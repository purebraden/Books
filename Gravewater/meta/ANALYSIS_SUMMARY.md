- **Issue:** 27.7% of sentences start with "The [noun] [verb]", "He [verb]", or "Kael [verb]"
- **Recommendation:** Vary sentence openings with:

  - Adverbs ("Quietly, he...")
  - Participial phrases ("Moving through...")
  - Questions or exclamations
  - Dependent clauses

### 2. Repetitive Phrases
- **Issue:** Phrases like "kael felt the", "that was the", "by the time" appear frequently
- **Recommendation:** 
  - Replace "Kael felt the" with variations: "A sensation of...", "The weight of...", "Pressure built..."
  - Vary "that was the" with: "That marked the", "That signaled the", "That became the"
  - Use "by the time" sparingly; try "when", "as", "once"

### 3. "Not [adjective]" Pattern
- **Issue:** 136 occurrences of this pattern
- **Recommendation:** Use positive descriptions where possible:
  - "Not large" → "small", "compact"
  - "Not fast" → "slow", "deliberate"
  - "Not safe" → "dangerous", "risky"

### 4. Dialogue Tags
- **Issue:** "the man said" appears 18 times
- **Recommendation:** Vary dialogue tags and use action beats:
  - "he said" → "he murmured", "he whispered", "he snapped"
  - Or use action: "He set down the coin. 'Take it.'"

### 5. "Felt" Usage
- **Issue:** 71 occurrences of "felt"
- **Recommendation:** Show rather than tell:
